Welcome to **opentide.org** — the public home for the OpenTide DetectionOps engine.

## What you'll find here

This site unifies content that previously lived across multiple repositories:

- **Specifications** — normative specs from the [specifications](https://github.com/OpenTideHQ/specifications) repo
- **Usage, CLI, MCP, SDK** — user documentation synced from [opentide](https://github.com/OpenTideHQ/opentide)
- **Blog** — announcements and engineering posts published from this repository
- **Registry** — coming soon: a browsable detection object registry powered by ShareTide

## Built for agents

OpenTide is agent-native. The MCP server, portable skills, and structured validation responses are first-class — not bolted on. If you're wiring up Cursor, VS Code, or another MCP client, start with the [MCP installation guide](/docs/mcp/installation/).

## DetectionOps

We believe detection engineering deserves the same rigour as software delivery: versioned schemas, CI validation, reproducible deploys, and honest platform capability reporting. OpenTide is our answer — and this site is where the practice is documented.
