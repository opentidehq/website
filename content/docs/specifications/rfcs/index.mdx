## Process

1. Open a GitHub [spec-change issue](https://github.com/OpenTideHQ/specifications/blob/main/.github/ISSUE_TEMPLATE/spec-change.yml) (never Linear; opentide tracking is public GitHub only)
2. Draft an RFC from [0000-template.md](/docs/specifications/rfcs/0000-template/)
3. Maintainer review and acceptance
4. Update specs, fixtures, `SPECS.md`, and `CHANGELOG.md` in the same PR as the RFC, unless the request is for an RFC draft only
5. Implement opentide changes separately
