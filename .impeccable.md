# OpenTide — Impeccable Design Context

## Design Context

### Target audience
Detection engineers, security platform operators, and AI-agent integrators building detection-as-code repositories across enterprise SIEMs.

### Use cases
Evaluate OpenTide, install the engine, wire MCP for agents, read normative specs, and adopt DetectionOps workflows in CI.

### Brand personality / tone
**Coastal precision** — deep EU-blue tides, golden signal highlights, pixel-ocean motion (Fumadocs-inspired charm), engineering credibility without corporate sterility. Agent-forward but human-first.

### Aesthetic direction
- **Register**: Marketing / product landing (expressive hero, restrained product UI elsewhere)
- **Motif**: The tide — rising water carrying detection objects, moonlit ops, pixel waves
- **Colors**: EU Pantone Reflex Blue `#003399`, EU Yellow `#FFCC00`, abyss `#000b1f`, foam `#7ec8e3`
- **Typography**: Inter (sans), JetBrains Mono for code
- **Motion**: One hero signature (pixel tide canvas); CSS stagger for cards; respect `prefers-reduced-motion`
- **Differentiation**: Animated pixel tide scene — unforgettable, on-brand, not generic gradient blobs
